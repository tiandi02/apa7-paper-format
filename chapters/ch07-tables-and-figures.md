# 手册第 7 章：表格与图

> 来源锚点：APA (2020), *Publication Manual* (7th ed.), Chapter 7, §7.1–7.36；与 `references/formatting.md` 第 11 节配合使用。

## Core Idea

表格与图的唯一目的是帮助读者理解；每个表图必须独立可读，不重复正文，也不能只是装饰。选择表格还是图，取决于你要强调精确数值还是模式与关系（§7.1–7.3）。

## Frameworks Introduced

- **Table vs Figure Decision（表格/图判定）**：需要精确保留每个数值或文字条目时用表；需要显示趋势、交互、分布、概念模型或图像时用图；少数均值和检验结果留在正文即可。
- **Canonical Form（规范形式）**：优先使用领域内读者熟悉的表格图形式（如相关矩阵、参与者流程图、森林图），只有在数据特性能证明必要时才使用非标准形式（§7.2、§7.21）。
- **Independent Readability（独立可读）**：读者不看正文也能理解表图；所有列、坐标轴、符号、图例和缩写都要在表图内说明（§7.2、§7.15、§7.28）。
- **Note Hierarchy（注的层级）**：一般注 → 特定注 → 概率注。`Note.` 斜体开头，之后依次说明整表/整图信息、特定单元格或面板、显著性符号（§7.14、§7.28）。

## Key Concepts

- **Callout**：正文按编号提及每个表图，并说明读者应看什么；写“see Table 1”“Figure 2 shows…”，不要写“the table above”“the figure on page 32”（§7.5）。
- **Placement**：所有表图左对齐。可全部放在参考文献后、每个表图单独一页，也可嵌入正文首次提及后；嵌入时放在完整段落后，若同页有正文，与表图之间留一个双倍行距空行（§7.6）。
- **Table components**：number（加粗，左上）→ title（斜体、title case，下一行）→ headings（sentence case，每列都有标题）→ body → notes（§7.9–7.14）。
- **Table title**：简短、清晰、可推断主要数据；避免过泛或重复表头细节；缩写可在标题或一般注中定义（§7.11）。
- **Table headings**：stub column 位于最左列，通常列自变量或预测变量；stub entries 用平行结构；column spanners 覆盖两列以上；decked heads 尽量不超过两级；table spanners 横跨全表（§7.12）。
- **Table body**：表体可单倍、1.5 倍或双倍行距；同类数值保留相同小数位；不适用的单元格留空并说明，数据缺失用 dash 并在一般注说明；相关矩阵主对角线 dash 不需说明（§7.13）。
- **Borders and shading**：只用顶线、底线、表头下线和必要的 spanner/total 线；禁止竖线；不以阴影装饰；需要强调时用注、斜体或粗体并说明（§7.17）。
- **Long or wide tables**：跨页时重复表头；横向表可 landscape，仍过宽则重复 stub column；既宽又长则拆成多个表（§7.18）。
- **Relation between tables**：相同数据不跨表重复；不能拆成 Table 1A/1B；相似数据用一致术语、格式和标题（§7.19）。
- **Figure components**：number（加粗）→ title（斜体 title case）→ image → legend（图内）→ notes（§7.23）。
- **Figure image**：图像清晰、线条平滑、坐标轴有标签和单位、元素可区分；图内使用 8–14 pt 无衬线字体；标题大小写、数字和统计符号按手册（§7.26）。
- **Color and accessibility**：色彩必须保证对比度，并能为色觉缺陷读者和灰度打印所理解；不要只靠颜色区分元素，可加线条样式或图案；避免装饰性网格线和 3-D 效果（§7.26）。
- **Panels**：多面板图可用 A、B 标签，正文写 Panel A of Figure 5 或 Figure 5A；无标签时用 top/left/middle panel 指代；一般注逐一说明面板（§7.26）。
- **Legends**：图例解释符号、线型、阴影或图案，置于图内或图下方；图例字母风格与图内一致（§7.27）。
- **Photographs and biological data**：可识别人物照片须取得签署 release；超出简单裁剪和亮度调整的图像修改要在注中说明；电生理、影像和遗传数据要标明处理方式、坐标空间、标尺、染色材料和标签（§7.30–7.34）。
- **Reprinting or adapting**：转印或改编表图需要 copyright attribution，可能还需 permission；在一般注末尾说明（§7.7、§12.14–12.18）。

## Mental Models

- 把表图当成“可脱离正文的数据说明书”：任何缩写、单位、符号和样本量都要自洽。
- 把正文中的 callout 当成导览：告诉读者看哪一行、哪一列或哪个面板，而不是只说“见表”。
- 把表格的横线当作语法标点：只在结构需要处分隔，不用竖线和阴影制造网格。
- 把图的可访问性当成硬要求：灰度、色觉缺陷和黑白打印都不应丢失信息。

## Anti-patterns

- **表图重复正文数据**：占用版面且分散读者注意力。
- **标题过泛或重复表头细节**：无法让读者快速判断表图内容。
- **使用竖线、单元格边框和装饰性阴影**：违反 APA 表格结构。
- **只靠颜色区分元素**：灰度打印或色觉缺陷读者可能丢失信息。
- **正文写 “see the table below”**：页面位置会变化，应按编号 callout。
- **转印或改编表图不写 copyright attribution**：造成版权和伦理问题。

## Reference Tables

| 展示目的 | 首选形式 | 理由 |
|---|---|---|
| 少数均值与 SD | 正文 | 一张表只放两三个数字不值得占用版面 |
| 多组描述统计 | 表 | 精确保留数值，便于比较 |
| 相关矩阵 | 表 | 规范形式，读者知道如何读 |
| 交互作用或趋势 | 折线图/图 | 图形强调模式 |
| 参与者流程 | 流程图 | 节点和排除原因需要顺序 |
| 多个面板的同类比较 | 多面板图 | 面板并列便于比较 |
| 荧光染色或脑影像 | 图 + 注 | 图像信息无法用表格替代 |

## Worked Example

正文写道：“干预组的均值是 5.2，控制组是 4.1；两组在三个时间点的分数分别为……，交互检验 F(2, 88) = 4.62, p = .012。”

处理：

1. 三个时间点 × 两组的均值和 SD 放 Table 1，标题写 “Mean Scores by Condition and Time Point”。
2. 交互作用用 Figure 1 折线图呈现，x 轴为 Time Point，y 轴为 Mean Score，两条线分别标注 Intervention 和 Control。
3. 正文保留 callout 和关键解释，不重复表中的全部数值。
4. 表一般注定义 CI 和缩写；概率注写 `*p < .05. **p < .01.`（按实际阈值）。

## Key Takeaways

1. 每个表图必须必要、独立可读、能在正文中被明确 callout。
2. 表图编号按正文首次提及顺序；正文只按编号引用，不按页面上位置引用。
3. 表题与图题用 title case，表内标题和文字用 sentence case。
4. 表格只用必要横线、无竖线、无装饰性阴影；跨页重复表头。
5. 一般注、特定注、概率注按固定顺序排列。
6. 图内字体 8–14 pt、无衬线、对比充分，颜色不能成为唯一编码方式。
7. 转印或改编表图要写 copyright attribution，并核查 permission。
