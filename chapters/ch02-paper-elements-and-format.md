# 手册第 2 章：论文要素与格式

> 来源锚点：APA (2020), *Publication Manual* (7th ed.), Chapter 2, §2.1–2.28；与 `references/formatting.md` 配合使用。

## Core Idea

格式的价值在于让读者把注意力放在内容上：所有论文要素按固定顺序出现，同一要素在全文中保持一致的字体、间距、缩进、标题层级和编号。学生论文与专业论文的“必备要素”不同，必须先判定文档类型（§2.1–2.2）。

## Frameworks Introduced

- **Professional vs Student Paper（专业论文与学生论文双轨）**：专业论文含 running head、作者注和摘要等投稿要素；学生论文通常只需标题页、页码、正文和参考文献，除非教师另有要求。
- **Paper Elements Sequence（论文要素序列）**：标题页 → 摘要 → 正文 → 参考文献 → 脚注 → 表格 → 图 → 附录（§2.17）。
- **Five-Level Heading System（五级标题系统）**：1 级居中加粗；2 级左对齐加粗；3 级左对齐加粗斜体；4 级缩进加粗并以句点结尾；5 级缩进加粗斜体并以句点结尾（§2.27，Table 2.3）。
- **Section Labels（节标签）**：Abstract、References、Author Note、Appendix A 等标签置于该节首页顶部，单独一行、加粗、居中（§2.28）。

## Key Concepts

- **Required elements**：学生论文与专业论文只在 running head、作者注、摘要等少数要素上不同；正文、参考文献和页码要求相同（§2.1–2.2）。
- **Title page**：标题 title case、加粗、居中并位于页面上半部；作者、单位、课程、教师、截止日期依次居中，每项一行（§2.3–2.5）。
- **Author affiliation**：多作者多单位时用上标数字对应单位；每位作者最多列两个单位（§2.6）。
- **Author note**：一般按 ORCID iDs、单位变更、利益冲突/资助/致谢、通讯作者信息四段组织；正文段落左对齐、首行缩进 0.5 英寸（§2.7）。
- **Running head**：仅专业论文使用；全大写、≤50 字符、左对齐，与右对齐页码同一行（§2.8、§2.18）。
- **Abstract and keywords**：摘要 ≤250 词、独立成页、单段、首行不缩进；关键词置于摘要下方，斜体“Keywords:”后用逗号分隔、结尾无句点（§2.9–2.10）。
- **Supplemental materials**：只放有助于理解但不适合或不需要放入正文的材料；正文要提及并简要说明（§2.15）。
- **Font**：同一论文统一使用 12-pt Times New Roman、11-pt Calibri、11-pt Arial 或 11-pt Georgia 等允许字体；图内文字使用 8–14 pt 无衬线字体（§2.19）。
- **Spacing, margins, alignment, indentation**：全文双倍行距；四边 1 英寸；左对齐；每段首行缩进 0.5 英寸，摘要首行和块引用等按例外处理（§2.21–2.24）。
- **Organization**：先写提纲，再按逻辑层级设置标题；同一节要么有至少两个子标题，要么完全没有（§2.26–2.27）。

## Mental Models

- 先问“这是学生论文还是投稿论文”，再决定是否写 running head、作者注和摘要。
- 把页序当成一条流水线：每个要素在固定位置出现，读者不需要搜索。
- 把标题层级当成目录的可视化：同级内容用同级标题，不能因为想强调就随意跨级。
- 把“Introduction”视为正文标题本身，不另设名为“Introduction”的 1 级标题。

## Anti-patterns

- **学生论文误加 running head、作者注和摘要**：除非教师或机构明确要求。
- **标题前后或段落之间加空行**：APA 用双倍行距而非额外空行分隔。
- **同一节只有一个子标题**：结构不对称；应至少两个同级子标题或完全不用子标题。
- **用 Tab 或空格伪造表格对齐**：版面易错，投稿排版会失效。
- **把 “Introduction” 写成 1 级标题**：正文首页重复的论文标题已经承担该功能。

## Reference Tables

| 格式项 | 默认规则 |
|---|---|
| 纸张与页边距 | US Letter；四边 1 英寸（学位论文装订可由学校另定） |
| 行距 | 全文双倍；表格主体、图内文字和脚注可例外 |
| 对齐 | 左对齐，不两端对齐 |
| 段落缩进 | 首行 0.5 英寸；摘要首行不缩进；参考文献悬挂缩进 0.5 英寸 |
| 标题页页码 | 第 1 页，右上角 |
| 标题大小写 | 所有标题与表图题使用 title case；参考文献条目中的作品标题用 sentence case |
| 节标签 | 加粗、居中、单独一行 |
| 附录编号 | Table A1、Figure C2；每个附录独立计数 |

## Worked Example

一份学生实证论文可按以下顺序组装：

1. 标题页（第 1 页，无 running head）。
2. 正文（新起一页，顶部重复论文标题作为事实上的 1 级标题）。
3. References（新起一页，加粗居中）。
4. 表格与图（按教师要求放在参考文献后或嵌入正文首次提及处）。
5. 附录（每个附录新起一页）。

标题层级可设为：Method、Results、Discussion 为 1 级；Participants、Measures、Data Analysis 为 2 级；涉及具体实验时，Experiment 1 与 Experiment 2 同级，其下再放 Method 与 Results。

## Key Takeaways

1. 学生论文与专业论文的要素差异要先判定，不要默认套用 running head 和作者注。
2. 页序、字体、行距、页边距和缩进一旦确定，全文保持一致。
3. 标题层级必须成对出现：有 2 级标题的节至少要两个同级标题。
4. 正文首页重复论文标题，但不要写“Introduction”标题。
5. 表格、图、附录、脚注的编号和位置要与正文提及顺序一致。
6. DOCX 交付前同时做 XML 结构检查和 PDF 渲染检查。
