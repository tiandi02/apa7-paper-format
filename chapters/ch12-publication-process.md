# 手册第 12 章：出版流程

> 来源锚点：APA (2020), *Publication Manual* (7th ed.), Chapter 12, §12.1–12.24。

## Core Idea

出版是作者、编辑、审稿人和出版社共同完成的流程：从期刊选择、投稿、同行评审、修改、录用、校样到出版后更正和传播。作者应选择 appropriate 且 reputable 的期刊，一次只投一家，遵守伦理和版权要求，并在录用后负责校对与后续记录维护（§12.1–12.24）。

## Frameworks Introduced

- **Appropriateness over Prestige（适合优先于声望）**：先判断期刊的 populations、methods、themes 和 article features 是否与稿件匹配，再考虑影响因子、拒稿率等声望指标（§12.2–12.3）。
- **Two-Journal Priority List（两家目标期刊）**：预先选定首选期刊和备选期刊；社会科学通常一次只能投一家，因此按适合度排序（§12.3）。
- **Predatory Journal Red Flags（掠夺性期刊红旗）**：非正式邀稿、隐藏出版商、缺乏严格评审、信息不透明、声誉差、非标准投稿系统、未被可信数据库收录等（§12.4）。
- **Editorial Decision Path（编辑决定路径）**：desk reject、peer review、accept、invite to revise and resubmit、conditional acceptance、reject；修改不保证录用，但 response to reviewers 有助推进（§12.7–12.8）。
- **Copyright Attribution Trigger（版权归属触发条件）**：转印或改编表、图、图像、数据、测验项目或长引文时，除参考文献外还要写 copyright attribution，并判断是否需要 permission（§12.14–12.18）。

## Key Concepts

- **Dissertation/thesis conversion**：可直接采用 multiple-paper format，或答辩后按期刊重塑篇幅、文献、引言、Method、Results/Discussion 和表图（§12.1）。
- **Journal selection**：看参考文献中反复出现的期刊、期刊主题、方法与人口群体匹配度；联系编辑确认范围；考虑开放获取、审稿时间、费用和国际读者（§12.2）。
- **Journal vetting**：高质量期刊通常有 DOI、ISSN、明确范围、清楚描述的评审/更正/撤稿流程、可识别的出版商和编辑委员会；可用 DOAJ、QOAM、Think. Check. Submit. 等资源核查（§12.4）。
- **Editor roles**：editor-in-chief 有最终决定权；associate/action editor 负责具体稿件；consulting/advisory editor 和 ad hoc reviewers 提供评审建议（§12.6）。
- **Peer review**：行动编辑邀请若干同行评审；评审人若缺乏胜任力应说明；编辑决定可不同于任何评审人建议（§12.7）。
- **Masked review**：可双向、单向或不匿名；作者须在匿名稿中隐藏身份、具体机构和可识别地点，并处理自我引用（§12.7）。
- **Review timing**：同行评审通常约 2–3 个月；超过 3 个月无消息可礼貌联系编辑（§12.7）。
- **Manuscript decisions**：accept 后进入 copyediting/typesetting；revise and resubmit 需提交 tracked changes 和 response to reviewers；reject 后可改投其他期刊，未经邀请不得改投同一期刊（§12.8）。
- **Manuscript file**：包括 title page、abstract、正文、参考文献、表图、脚注和附录；匿名评审时可能要求 title page 单独上传；补充材料通常不经 copyediting（§12.10）。
- **Cover letter**：说明稿件信息、全体作者同意内容和顺序、相近稿件情况、利益冲突、是否请求 masked review、伦理合规、permission 状态和通讯作者联系方式（§12.11）。
- **Corresponding during publication**：通讯作者通常负责与编辑沟通；所有往来包含完整标题、作者名和稿件编号；录用后通讯作者继续回应文章问题（§12.12）。
- **Ethical certification**：投稿时可能要求 IRB/IACUC 证明、Certificate of Compliance With APA Ethical Principles、Full Disclosure of Interests；无利益冲突也要明确声明（§12.13）。
- **Plagiarism detection**：出版商常用软件比对已发表文献和公开网页；作者仍须自行确保引用和重复使用合规（§12.13）。
- **Reprinting vs adapting**：reprinting 是不改动地复制；adapting 是修改后用于新目的。两者通常都需要 copyright attribution，并可能需 permission；attribution 代替文内引用，但作品仍需进参考文献（§12.14–12.15）。
- **Material types requiring attribution**：表、图、照片、infographic、screenshot、数据、测验/量表项目、问卷、vignette、长引文、歌曲、诗歌和艺术作品等（§12.15）。
- **Copyright status**：standard copyright、Creative Commons、public domain、未标明版权（按受版权保护处理）。CC 和 public domain 通常不需 permission，但仍需 attribution；美国政府作品通常属 public domain（§12.16）。
- **APA permission thresholds**：用于学术评论、非商业研究或教育；完整准确归属；来自同一期刊文章或书章最多三个表图；单段文字少于 400 词或系列摘录总计少于 800 词时，APA 通常不要求书面 permission。其他出版商政策可能更严格（§12.17）。
- **Fair use criteria**：用于学术、非营利目的；主要复制事实或数据而非创造性表达；相对于原作品比例小且非核心；不影响原作品市场。判断不确定时联系版权方（§12.17）。
- **Identifiable photographs**：照片中人物可识别时须取得签署 release，授权印刷和电子使用；作者本人照片通常不需要（§12.17）。
- **Securing permission**：向版权方书面申请，说明作品信息和使用性质；留存许可函；按 APA 期刊要求提交 Permissions Alert Form；在稿件中写 attribution；等待许可可能需要数周（§12.17）。
- **Proofs**：校样阶段只修正拼写、语法、排版错误和失效 DOI/URL；不得重写文本、新增分析、引用或解释；逐项回答 copyeditor 提问，检查作者名、单位、标题层级、数字、表图标签和注（§12.19）。
- **Copyright transfer**：录用后通常把版权转让给出版社；美国联邦雇员在职务范围内创作的作品可能属于 public domain；合同作品可能由出版社保留版权但授予政府使用权（§12.20）。
- **Open access**：资助方或机构可能要求预印本、accepted manuscript 或最终文章存入指定仓库；投稿前核对开放获取政策（§12.21）。
- **Correction notice**：需说明错误内容、正确信息、哪些版本已更正；不指认责任；作者顺序变更、单位重大变更、替换参考文献、数据修改、改变意义的文字修改等需要正式更正；细小 typo 通常不需要（§12.22）。
- **Sharing article online**：多数出版社允许在预印本、机构仓库、个人网站等发布 accepted manuscript，但通常不得发布最终排版版；须附版权声明和最终文章 DOI（§12.23）。
- **Promoting article**：可用 plain-language summary、impact statement、新闻稿和社交媒体传播研究；语言要清晰、结果要准确，不夸大（§12.24）。

## Mental Models

- 把期刊选择当成匹配问题：读者是否会在这里找到你的研究。
- 把投稿信当成合规声明：作者同意、相近稿件、利益冲突、伦理与权限一次说清。
- 把 permission 当成时间敏感的前置条件：许多出版社在 permission 齐备前不进入 production。
- 把校样当成最后的质量门，而不是最后一次改写机会。
- 把更正视为保护科学记录，而不是承认失败的耻辱。

## Anti-patterns

- **同时投多家期刊**：不符合社会科学出版规范。
- **只看影响因子不做期刊匹配和 predatory 核查**：提高 desk reject 与发表风险。
- **permission 未齐备就投稿**：出版社可能延迟或拒绝进入 production。
- **校样阶段重写或新增分析**：超出校对范围，可能需要重新评审。
- **发布最终排版版文章**：违反多数出版社的 self-archiving 政策。
- **发现实质错误却不更正**：破坏科学记录和读者信任。

## Reference Tables

| 阶段 | 必须做的动作 | 常见风险 |
|---|---|---|
| 选刊 | 核对范围、方法、读者、开放获取和声誉 | 只看影响因子；投 predatory journal |
| 投稿 | 按门户上传稿件、cover letter、补充材料 | 同时投多家；格式不合要求 |
| 评审 | 回应全部意见；提交 tracked changes 与 response | 忽略意见或不说明不同意理由 |
| 录用 | 完成版权、利益冲突、permission 文件 | 文件不全导致延迟或撤回录用 |
| 校样 | 只改错误；回答 copyeditor 查询 | 校样阶段重写或新增分析 |
| 出版后 | 维护记录；必要时更正/撤稿；合规分享 | 发布最终排版版；不更正实质错误 |

| 材料 | 是否需要 attribution | 是否需要 permission |
|---|---|---|
| CC 许可或 public domain 表图 | 需要 | 通常不需要 |
| 受版权保护的表图，在 APA 政策阈值内 | 需要 | APA 通常不需要 |
| 超过阈值或来自其他出版商 | 需要 | 按版权方政策，通常需要 |
| 重新分析后产生的新数据 | 普通 author–date 引用 | 通常不需要 |
| 直接复制测验项目 | 需要 | 通常需要 |

## Worked Example

你的论文要转印某 APA 期刊文章中的一张图：

1. 确认图片来自受版权保护的文章，且你只使用一张图，属于学术、非营利用途。
2. 按 APA 政策，通常不需要书面 permission，但仍需完整 copyright attribution。
3. 在 figure general note 末尾写 attribution，说明 From/Adapted from、文章标题、作者、年份、期刊名、卷期页码和 DOI，并注明版权归属。
4. 在参考文献列表保留该文章的完整条目。
5. 如果来源不是 APA 期刊，或其政策要求 permission，则提交许可申请、留存许可函，并等待批准后再投稿。

## Key Takeaways

1. 先选适合的期刊，再考虑声望；一次只投一家。
2. 用 DOAJ、QOAM、Think. Check. Submit. 等工具识别掠夺性期刊。
3. cover letter 要覆盖作者同意、相近稿件、利益冲突、伦理和权限状态。
4. 转印或改编表图、数据、测验项目、长引文时，写 attribution 并判断 permission。
5. CC 与 public domain 通常不需 permission，但仍需 attribution。
6. 校样只改错误，不改研究内容。
7. 实质错误需要正式 correction notice；严重问题可能撤稿。
8. 在线分享通常只能发布 accepted manuscript，并附 DOI 和版权声明。
