# APA 7 数字与统计符号（手册第 6 章）

> **外部要求优先**：期刊投稿要求、学校模板、教师要求优先于本文件所述默认规则；冲突时以外部要求为准，并在交付时注明偏差。

## 1. 数字：阿拉伯数字 vs 单词（6.32–6.39）

**用阿拉伯数字**：
- 10 及以上的数字（含摘要）
- 紧接测量单位的数字：`5-mg dose`、`10.5 cm`
- 统计/数学量、小数、百分比、比例、百分位数：`0.33 of the sample`、`more than 5%`、`the 5th percentile`
- 时间、日期、年龄、量表分数、金额：`5 days`、`2-year-olds`、`scored 4 on a 7-point scale`
- 序号位置：`Table 2`、`Chapter 1`、`Grade 10`（数字在名词后）

**用单词**：
- 0–9 的数字（例外见上）
- 句首数字（尽量改写句式避免）：`Forty-eight percent of the sample...`
- 常用分数：`one fifth of the class`

**组合**：连用的数字修饰语一用数字一用单词：`2 two-way interactions`、`ten 7-point scales`

- 千位以上加逗号（页码、序列号、二进制、温度、频率、自由度除外）
- 复数不加撇号：`twos and sixes`、`the 1960s`
- 序数词上标可用可不用，但全文统一

## 2. 小数与 p 值（6.36）

- 统计量可能 >1 时小数前加 0：`t(20) = 0.86`、`Cohen's d = 0.70`
- 不可能 >1 时（相关、比例、显著性）**不加前导 0**：`r(24) = -.43, p = .028`
- 一般保留两位小数；整数量表上的均值/标准差保留 1 位；p 值保留 2–3 位，**p < .001 记作 p < .001**（不再写 p < .01 之类）
- 相关、比例、t/F/χ² 报告到两位小数

## 3. 正文中的统计报告（6.43）

- 用词不用符号叙述："the means were"，不写 "the Ms were"
- 带数值时用符号：`(M = 7.74)`
- 给出足够信息供读者复核，例：
  - `F(2, 177) = 6.30, p = .002, est ω² = .07.`
  - `t(177) = 3.51, p < .001, d = 0.65, 95% CI [0.35, 0.95].`
  - `High school GPA predicted college mathematics performance, R² = .12, F(1, 148) = 20.18, p < .001.`
- 置信区间格式：`95% CI [LL, UL]`；同一段重复时不必每次写 "95%"
- 多个统计量与对象对应关系要清晰（用 respectively / in order）
- 表格已呈现的描述统计不要在正文重复，但要在正文提及该表

## 4. 统计符号格式（6.44，Table 6.5 摘要）

| 符号 | 含义 | 注意 |
|---|---|---|
| *N* | 总样本量 | 大写斜体 |
| *n* | 子样本量 | 小写斜体 |
| *M* | 均值 | 斜体 |
| *SD* | 标准差 | 斜体 |
| *SE* | 标准误 | 斜体 |
| *Mdn* | 中位数 | 斜体 |
| *t* | t 检验 | 斜体 |
| *F* | F 检验 | 斜体 |
| χ² | 卡方 | 标准体（roman） |
| *p* | 显著性 | 斜体、无前导 0 |
| *r* | 相关系数 | 斜体、无前导 0 |
| *R²* | 决定系数 | 斜体 |
| *d* | Cohen's d | 斜体 |
| CI | 置信区间 | 缩写首次出现需定义（在表注/正文） |
| α/β | I/II 类错误、Cronbach's α | 希腊字母用标准体 |

- 希腊字母（α、β、χ²、Σ、μ）用标准体（不斜体）；拉丁字母统计符号斜体
- 向量/矩阵用粗体
- 负号用真正的减号 −（不是连字符 -），紧贴数值、其后不留空格，其前按运算符规则留空格：`r = −.43`
- 下标写在上标之前；作为标识符的下标/上标（如 x₁ 中的 girls）不斜体
- 常见统计量符号（M、SD、F、t、d、p、N、n、OR、r）**不用定义**；其他缩写（ANOVA、CFA、CI、EFA、RMSEA、SEM 等）首次出现时定义
- 常用统计量（如 Cohen's d）不需要参考文献；冷门统计量需要
- 总体参数用希腊字母，估计量用斜体拉丁字母

## 5. 百分号与货币（6.44）

- 有数字时用符号：`18%-20%`（范围重复符号）
- 无数字时用单词："the percentage"
- 货币同理：`$10.50`，但 "in U.S. dollars"

## 6. 数量呈现形式选择（6.40）

- ≤3 个数字：用句子；4–20 个数字：用表格；>20 个数字：用图

## 7. 标题大小写（6.17）

**Title case**（用于：论文标题、各级标题、表格/图题、期刊名、测验名）：
- 首词首字母大写；冒号、破折号、句末标点后的首词也大写
- ≥4 个字母的主要词大写（名词、动词、形容词、副词、代词，以及 ≥4 字母的介词/连词如 Between、With、Because）
- ≤3 字母的冠词、连词、介词小写（a、an、the、and、but、or、nor、for、so、yet、if、at、by、in、of、on、to、up、as、per、via），位于首词位置（或冒号/破折号/句末标点之后）时大写
- 冒号或破折号后的首词大写
- 连字符复合词两部分都大写：Self-Esteem、Meta-Analysis
- 不定式中的 to 小写：How to Write a Paper

**Sentence case**（用于：参考文献中的作品标题、图注中的作品名等）：
- 仅首词、冒号或破折号后首词、专有名词大写，其余一律小写

## 8. 公式排版（6.45–6.47）

- 数学符号之间如单词一样留空格：`a + b = c`（不是 a+b=c）
- 负号/减号用真正的减号 −，不用连字符 -
- 简单短公式可嵌在行内；较长或复杂的公式单独成行显示
- 显示的公式如需要被引用，按出现顺序编号，编号用圆括号放在行尾（右对齐）：（1）、（2）……正文引用时写"见公式 1"
- 变量斜体；数字、函数名（log、exp）与括号不斜体
- 只有不常见或论文核心的公式才需给出（6.42）；常见统计量（如 Cohen's d）不写公式
- 脚本支持**真正的 Word 公式对象**（OMML）：正文 `[EQ]d = \frac{\sum_{i=1}^{n} (x_i - M)^2}{n - 1}` 生成居中公式 + 右对齐编号 (1)(2)……（编号自动生成并带书签）；正文用 `{EQREF:1}` 交叉引用；公式方言支持 `\frac{a}{b}`、`\sqrt{x}`/`\sqrt[3]{x}`、`_` 下标、`^` 上标、`\sum_{i=1}^{n}` 等上下限、希腊字母（`\alpha`、`\Sigma`……）、`{...}` 分组；变量自动斜体、函数名正体
