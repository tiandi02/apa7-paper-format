# 手册第 9 章：参考文献列表

> 来源锚点：APA (2020), *Publication Manual* (7th ed.), Chapter 9, §9.1–9.52；与 `references/reference-list.md` 配合使用。

## Core Idea

参考文献列表是检索地图：每条条目回答 Who、When、What、Where 四个问题，读者据此找到并核对正文引用的作品。先确定 reference group、category 和 type，再按最接近的模板填写，而不是为每种作品发明一套格式（§9.1–9.4）。

## Frameworks Introduced

- **Four Elements（四要素）**：author（谁负责）、date（何时出版）、title（作品叫什么）、source（从哪里取得）。这是处理手册未直接给出示例的新类型时的通用框架。
- **Group → Category → Type（组—类别—类型）**：textual works、data sets/software/tests、audiovisual media、online media 为组；组下分类别；类别下有具体类型。先判断作品本质，再选择模板（§9.1）。
- **Webpages and Websites Fallback（网页类别兜底）**：只有当作品不属于其他更具体类别时才使用 webpages and websites；先问“网站上放的是什么类型的作品”（§9.2）。
- **Missing Element Fill（缺失要素填补）**：缺作者时标题前移；缺日期写 n.d.；缺标题用方括号描述；缺来源时改作 personal communication 或换一个可检索作品（Table 9.1）。

## Key Concepts

- **Online and print**：在线版与印刷版使用同一模板，差别主要在 source 要素中是否包含 DOI/URL；数据库信息通常不写（§9.3、§9.30）。
- **Punctuation**：作者、日期、标题、来源后各一个句点；DOI/URL 后不加句点；同一要素内部用逗号或括号；斜体要素内部的标点也斜体，要素之间的句点不斜体（§9.5）。
- **Accuracy and consistency**：逐条对照原始作品核对；作者名拼写、年份、标题和来源必须准确，否则会影响检索、索引和读者信任（§9.6）。
- **Author element**：作者姓在前、名字首字母在后；≤20 位全部列出，≥21 位列前 19 位、省略号、最后一位；编者用 (Eds.)；特殊角色（导演、主持、上传者）用方括号或角色标签；群体作者写全称；无作者时标题移到最前（§9.7–9.12）。
- **Date element**：按作品类型给 (2020)、(2020, August 26)、(2020, Spring/Summer)、(n.d.) 或 (in press)；仅对会持续变化且未存档的网页加 retrieval date（§9.13–9.17）。
- **Title element**：属于更大整体的作品（期刊论文、书章）用 sentence case 且不斜体；独立作品（书、报告、网页、影片）用 sentence case 并斜体；版次、卷次、报告号放括号；非常规类型加方括号描述（§9.18–9.22）。
- **Source element**：期刊名和卷号斜体，期号不斜体；出版社名称按原样但省略 Inc./Ltd.；作者与出版社相同时省略出版社；章节用 “In … (Ed.), Title (pp. xx–xx). Publisher.”（§9.23–9.29）。
- **Database and archive**：学术数据库（PsycINFO、EBSCO、PubMed 等）通常不写数据库名；ProQuest Dissertations and Theses Global、ERIC、PsyArXiv、Cochrane、UpToDate 等属于需要写出的专有或受限来源（§9.30）。
- **DOI and URL**：有 DOI 必写，格式为 https://doi.org/xxxx；有 DOI 时不写 URL；无 DOI 的网页写能直接定位内容的 URL；URL 失效时尝试 Internet Archive；不写 “Retrieved from” 除非有 retrieval date；不使用短链接，除非作品本身采用短链接（§9.34–9.36）。
- **Variations**：外语作品给原文标题并在方括号内给英译；翻译作品在标题后注明译者与原出版年；重印、再版、重新发行、宗教与经典作品按专门格式（§9.38–9.42）。
- **Reference list format**：新起一页，“References” 加粗居中；全部条目双倍行距；悬挂缩进 0.5 英寸；按字母序排列（§9.43–9.49）。
- **Order rules**：忽略空格、标点和连字符进行字母比较；单作者排在共同第一作者的多作者之前；同作者按年份从早到晚（n.d. 最前、in press 最后）；同年同作者按标题字母序加 a/b/c；无作者按标题首词排序（忽略 A/An/The）（§9.44–9.49）。
- **Abbreviations**：参考文献中可使用 ed.、Rev. ed.、Ed. (Eds.)、Trans.、Narr.、p. (pp.)、Vol. (Vols.)、No.、Pt.、Tech. Rep.、Suppl.、n.d.、para. (paras.) 等标准缩写（§9.50）。
- **Annotated bibliography**：条目下方写注释，整段缩进 0.5 英寸，首行不额外缩进；多条注释的第二段起首行再缩进（§9.51）。
- **Meta-analysis references**：被纳入元分析的研究条目前加星号 *，并在 References 标签下加说明（§9.52）。

## Mental Models

- 把参考文献条目读成一个检索句：Who. (When). What. Where.
- 先判断作品本体，不受访问方式影响：在网页上读到的期刊文章仍是期刊文章，不是 webpage。
- 缺信息时先问“有没有可替代的可检索来源”，再考虑 personal communication 或不引用。
- 排序时先按作者名、再按年份、最后按标题；年份后缀由参考文献最终顺序决定。

## Anti-patterns

- **为同一作品同时套多个模板**：只选一个最接近的类别模板并混搭要素。
- **把网页上的文章归入 webpage/website**：先判断作品本质，再选类别。
- **在 DOI/URL 后加句点**：会破坏链接。
- **写数据库名或 “Retrieved from”**：除专有数据库和有检索日期的持续更新页面外都不写。
- **参考文献标题用 title case**：作品标题应使用 sentence case。
- **排序时忽略单作者优先或 n.d./in press 规则**：会造成顺序错误和文内引用不一致。

## Reference Tables

| 缺失要素 | 参考文献写法 | 文内引用 |
|---|---|---|
| 作者 | Title. (Date). Source. | (Title, year) |
| 日期 | Author. (n.d.). Title. Source. | (Author, n.d.) |
| 标题 | Author. (Date). [Description]. Source. | (Author, year) |
| 作者 + 日期 | Title. (n.d.). Source. | (Title, n.d.) |
| 来源 | 无条目，按 personal communication | (Initial. Surname, personal communication, date) |

| 作品形态 | 标题格式 |
|---|---|
| 期刊/报纸/杂志文章、书章 | sentence case，不斜体，不加引号 |
| 书、报告、网页、影片、数据集 | sentence case，斜体 |
| 非常规类型 | 标题后加 [Data set]、[Film]、[Computer software] 等 |
| 外语作品 | 原文标题 [English translation] |

## Worked Example

原始信息：期刊文章，作者 A. A. Smith 和 B. B. Lee，2021 年，标题 “Sleep and Memory in Young Adults”，期刊 *Journal of Experimental Psychology: Learning, Memory, and Cognition*，第 47 卷第 3 期，第 210–225 页，DOI 10.1037/xlm0000999。

参考文献：

> Smith, A. A., & Lee, B. B. (2021). Sleep and memory in young adults. *Journal of Experimental Psychology: Learning, Memory, and Cognition, 47*(3), 210–225. https://doi.org/10.1037/xlm0000999

文内引用：`(Smith & Lee, 2021)`；叙述引用：`Smith and Lee (2021)`。

要点：文章标题 sentence case 且不斜体；期刊名和卷号斜体；期号在括号内；DOI 用 https 格式且结尾无句点。

## Key Takeaways

1. 每条参考文献对应一个文内引用，例外情形按 §8.4 处理。
2. 先确定组、类别、类型，再套模板；访问方式不决定类别。
3. 四要素缺一不可，缺失时按 Table 9.1 调整。
4. 学术数据库名通常不写；DOI 优先于 URL；DOI/URL 后不加句点。
5. 参考文献列表双倍行距、悬挂缩进、按完整规则排序。
6. 同年同作者用 a/b/c，文内引用同步；n.d. 最前、in press 最后。
7. 元分析纳入研究加星号并在 References 标签下说明。
