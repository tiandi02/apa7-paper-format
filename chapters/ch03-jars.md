# 手册第 3 章：期刊论文报告标准（JARS）

> 来源锚点：APA (2020), *Publication Manual* (7th ed.), Chapter 3, §3.1–3.18。

## Core Idea

JARS（journal article reporting standards）规定论文“最低限度必须报告什么”，使读者能理解研究、评审者能判断价值、后续研究者能复现。它不规定如何设计或执行研究；任何实证研究至少要报告 Table 3.1 的基础要素，再根据设计追加 JARS-Quant、JARS-Qual 或 JARS-Mixed 的特定标准（§3.1–3.5）。

## Frameworks Introduced

- **JARS-Quant（定量研究报告标准）**：适用于定量、实验、非实验、纵向、N-of-1、复制和定量元分析研究；核心是方法、数据诊断、结果完整性和效应量（§3.5–3.12）。
- **JARS-Qual（定性研究报告标准）**：适用于定性研究；核心是研究背景、研究者反身性、参与者或数据来源、研究者—参与者关系、数据收集与分析、方法论完整性和证据化发现（§3.13–3.17）。
- **JARS-Mixed（混合方法报告标准）**：同时满足定量与定性标准，并额外说明两类证据如何整合；常见设计有 convergent、explanatory sequential、exploratory sequential（§3.18）。
- **Three Hypothesis Groups（三类假设）**：preplanned-primary、preplanned-secondary、exploratory（post hoc）；结果部分按同一顺序报告（§3.4、§3.7）。

## Key Concepts

- **Abstract**：准确、非评价、连贯、简洁；实证研究摘要要写问题、参与者或数据来源、设计、分析策略、样本量、材料、主要结果、结论与意义；定量结果尽可能写效应量与置信区间（§3.3）。
- **Introduction**：说明问题重要性、历史脉络、理论或实践意义；明确研究目标、假设或研究问题，并说明设计与目标的匹配（§3.4）。
- **Method**：报告参与者纳入与排除、样本量确定依据、测量工具、程序、研究设计、伦理审批与知情同意；复杂抽样、纵向留存、实验操纵保真度等按设计追加（§3.6、§3.9–3.11）。
- **Data diagnosis**：在结果前报告数据检查、缺失机制、排除、变换和插补决策，以及假设检验或模型诊断问题（§3.6–3.7）。
- **Results**：报告所有相关结果，无论是否支持假设；给出检验统计量、df、精确 p、效应量及其方向；点估计同时给精度指标；常用 CI；报告软件、参数设置与收敛问题（§3.7）。
- **Participant flow**：实验和准实验报告招募、分组、未完成、交叉、用于主要分析的样本量；可用流程图呈现（§3.7）。
- **Missing data**：说明缺失比例、可能机制（MCAR、MAR、NMAR）和处理方法（§3.7）。
- **Discussion**：先明确支持或不支持哪些假设，再讨论与既有研究的一致与差异、局限与优势、替代解释、泛化性、干预机制或路径，并提出结论（§3.8）。
- **Qualitative reporting**：定性论文可以合并 Results 与 Discussion，可使用 Findings 等传统术语；篇幅可更长，因为需要解释分析过程并展示原始材料（§3.13–3.16）。
- **Methodological integrity**：定性研究强调方法透明、反身性、证据与结论的适合性；不设统一最小样本量，作者须说明样本量或数据量的理由（§3.14）。
- **Mixed methods integration**：不仅分别报告定量与定性结果，还要说明二者如何 merged、connected 或 transformed；可用 joint display、implementation matrix 呈现（§3.18）。

## Mental Models

- 把 JARS 当成“审稿人检查表”：先写研究设计，再按设计选择报告表格，而不是写完再补。
- 把 Results 当成证据账本：每个结论都必须能追溯到统计量、效应量、区间估计和样本量。
- 把定性研究的“可信”理解为可追踪的分析过程和有材料支撑的解释，而不是量化标准。
- 把混合方法的核心问题设为“整合后多知道了什么”，而非“做了两种方法”。

## Anti-patterns

- **只报 p 值不报效应量和 CI**：读者无法判断效应大小与估计精度。
- **选择性报告显著结果**：违反完整报告要求，扭曲证据库。
- **把缺失数据、排除和插补藏在方法之外**：影响推断合法性。
- **定性研究套用定量样本量门槛**：定性研究需说明样本量理由而非统一最小值。
- **混合方法只并列两套结果**：没有整合就失去 mixed methods 的核心价值。

## Reference Tables

| 报告阶段 | 定量重点 | 定性重点 | 混合方法增量 |
|---|---|---|---|
| Abstract | 设计、样本、主要效应与 CI | 问题、设计、主要发现与意义 | 指出混合设计类型与整合结论 |
| Introduction | 假设与理论推导 | 问题、背景、研究目标与 inquiry approach | 分别说明定量、定性与整合目标 |
| Method | 抽样、设计、测量、程序、数据诊断 | 研究者位置、参与者/来源、关系、招募、分析 | 分开描述两套方法并说明连接方式 |
| Results/Findings | 全部检验、效应量、CI、模型问题 | 主题/模式、证据片段、解释过程 | 结果分栏 + 整合展示 |
| Discussion | 假设支持、局限、替代解释、泛化 | 意义、局限性、可信度、启示 | 整合后的新增洞见与边界 |

## Worked Example

一项“问卷 + 访谈”的研究要判断应使用 JARS-Mixed 而不是只写 JARS-Quant：

1. 说明采用 mixed methods 的理由，以及设计类型（如 explanatory sequential）。
2. 在 Method 中分别报告定量样本、抽样、测量与访谈对象、访谈流程。
3. 在 Results 中先呈现问卷结果，再用访谈解释问卷中的矛盾或极端模式。
4. 增加整合展示：joint display 把定量模式与对应主题并列，说明整合后多出什么解释。
5. Discussion 回应整合结论，并说明不能由两种方法互相替代的部分。

## Key Takeaways

1. 任何实证研究都从 Table 3.1 的基础标准出发，再追加对应设计标准。
2. 假设和结果按 primary、secondary、exploratory 三组一致呈现。
3. 不显著结果、反预期结果和不利证据必须报告。
4. 点估计必须配精度信息，推断性检验给统计量、df、精确 p、效应量和方向。
5. 定性研究的样本量与可信度要说明理由，不套用定量门槛。
6. 混合方法必须证明整合带来额外洞见，而非简单拼接两种研究。
7. JARS 网站有完整表格；本 skill 只保留手册第 3 章的导向内容。
