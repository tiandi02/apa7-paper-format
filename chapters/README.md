## 使用顺序

1. 先读 `SKILL.md` 的核心速查和现有 `references/`。
2. 需要章节背景或判定规则时，读对应 `chapters/chNN-*.md`。
3. 需要具体条目模板时回到 `references/reference-list.md`；需要版式细则时回到 `references/formatting.md`。
4. 需要 Word 生成、编辑或验证时按 `references/python-word-components.md` 执行。
